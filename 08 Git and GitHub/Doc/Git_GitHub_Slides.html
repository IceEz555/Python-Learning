พื้นฐาน

Git ≠ GitHub

Git

โปรแกรมที่ติดตั้งในเครื่องเรา ใช้บันทึกประวัติการแก้ไขไฟล์ (version control)

ใช้ได้แม้ไม่มีอินเทอร์เน็ต

GitHub

เว็บไซต์ที่เก็บ repository ของ Git ไว้บนอินเทอร์เน็ต ให้แชร์และทำงานร่วมกันได้

เปรียบเหมือน Google Drive สำหรับโค้ด

เปรียบเทียบง่ายๆ: Git คือกล้องถ่ายรูป ส่วน GitHub คืออัลบั้มออนไลน์ที่เอารูปไปเก็บและแชร์
คำศัพท์

คำที่ต้องรู้

คำความหมาย
Repository (repo)โฟลเดอร์โปรเจกต์ที่ Git ติดตามประวัติ
Commit"จุดบันทึก" ของงาน ณ เวลาหนึ่ง พร้อมข้อความอธิบาย
Cloneดาวน์โหลด repo จาก GitHub มาไว้ในเครื่อง
Push / Pullส่ง commit ขึ้น GitHub / ดึงของใหม่ลงมาในเครื่อง
Forkคัดลอก repo ของคนอื่นมาเป็นของเราบน GitHub
Pull Request (PR)คำขอให้เจ้าของ repo ดูและรับงานของเรา, เราใช้ส่งการบ้าน

เส้นทางการบ้าน 1 ชิ้น

ขั้นที่ 1

Fork repo ของครู

  1. เปิดลิงก์ repo Python-Learning ที่ครูให้
  2. กดปุ่ม Fork มุมขวาบน
  3. กด Create fork โดยไม่ต้องเปลี่ยนอะไร
  4. ดูว่าตอนนี้อยู่ที่ github.com/ชื่อเรา/Python-Learning
Fork ทำครั้งเดียวตลอดคอร์ส

การบ้านทุกชิ้นส่งจาก fork นี้ ไม่ต้อง fork ใหม่ทุกครั้ง
ขั้นที่ 2

Clone ลงเครื่อง

ใน fork ของเรา กดปุ่มสีเขียว Code แล้วคัดลอก URL แบบ HTTPS

# ไปที่โฟลเดอร์ที่จะเก็บงาน
cd Desktop

# ดาวน์โหลด repo ลงมา
git clone https://github.com/ชื่อเรา/Python-Learning.git

cd Python-Learning
ครั้งแรกที่ push จะมีหน้าต่างให้ Sign in with browser กดยอมรับได้เลย
Clone fork ของเรา ไม่ใช่ repo ของครู ไม่อย่างนั้นจะ push ไม่ได้

ขั้นที่ 4 · หัวใจของ Git

3 คำสั่งที่ใช้ทุกวัน

# ดูว่ามีไฟล์ไหนเปลี่ยนบ้าง
git status

# 1. เลือกไฟล์ที่จะบันทึก
git add submissions/6612345-somchai/

# 2. บันทึกพร้อมข้อความ
git commit -m "hw01: hello world"

# 3. ส่งขึ้น GitHub
git push

add

ใส่ของลงกล่อง

commit

ปิดกล่องและเขียนป้ายว่าข้างในมีอะไร

push

ส่งกล่องไปไปรษณีย์ (GitHub)

เขียนให้ดี

สูตร: ชื่องาน: ทำอะไรไป สั้นๆ ให้คนอ่านเข้าใจได้ทันที

ขั้นที่ 5 · ส่งงาน

เปิด Pull Request

  1. เข้า fork ของเราบน GitHub จะเห็นแถบ Compare & pull request ให้กดที่แถบนั้น
  2. เช็คทิศทาง: ครู/main ← เรา/main
  3. ตั้งชื่อ: [hw01] 6612345 สมชาย
  4. ติ๊ก checklist ในช่องรายละเอียด แล้วกด Create pull request
เปิด PR ครั้งเดียว แล้ว push เพิ่มได้เรื่อยๆ commit ใหม่จะเข้า PR เดิมอัตโนมัติ
ครูจะคอมเมนต์ในหน้า PR ให้กดดูแท็บ Conversation และ Files changed
ทุกสัปดาห์

ดึงบทเรียนใหม่จากครู

วิธีง่าย: ผ่านเว็บ

ใน fork ของเรา กด Sync fork → Update branch
แล้วในเครื่องพิมพ์ git pull

วิธี Terminal

# ทำครั้งแรกครั้งเดียว
git remote add upstream \
  https://github.com/ชื่อครู/Python-Learning.git

# ทุกครั้งที่ครูอัปเดต
git pull upstream main
git push

Cheat sheet

# ครั้งเดียว
git config --global user.name "..."
git config --global user.email "..."
git clone <url-fork-ของเรา>
# ทุกครั้งที่ทำการบ้าน
git pull
# ... ทำงาน + save ...
git status
git add submissions/รหัส-ชื่อ/
git commit -m "hwXX: ..."
git push

ดูประวัติ: git log --oneline · ดูสิ่งที่แก้: git diff

แบบฝึกหัด: ส่งงานชิ้นแรก

  1. Fork repo Python-Learning แล้ว clone fork ลงเครื่อง
  2. สร้างโฟลเดอร์ submissions/รหัส-ชื่อ/
  3. สร้าง hw00-hello.ipynb ที่ print() ชื่อ รหัส และสิ่งที่อยากเขียนด้วย Python
  4. add → commit -m "hw00: hello" → push
  5. เปิด Pull Request ชื่อ [hw00] รหัส ชื่อ

Checklist

  • รัน notebook ครบทุก cell และ save แล้ว
  • ไฟล์อยู่ใน submissions/รหัส-ชื่อ/ เท่านั้น
  • commit message บอกว่าทำอะไร
  • git push สำเร็จ และเห็นไฟล์บน GitHub
  • มี Pull Request เปิดอยู่ ชื่อถูกรูปแบบ
